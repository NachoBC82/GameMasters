# GameMasters
Project to test the methodology

## Story Json Format
- "speaker": "Actor que mostrar en pantalla" 
- "text": "Texto que dirá"
- "choices": [ lista de opciones a elegir. Deben tener el formato text, goto ]
- "goto":"Punto del dialogo al que saltar"
- "anchor":"Punto del texto al que se salta desde un goto"
- "location":"Escenario que cargar"
